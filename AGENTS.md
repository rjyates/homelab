# Homelab — agent instructions

Public documentation showcase of a personal homelab built around Home Assistant. It explains the work and design decisions; it is **not** a deployable copy of the private environment.

## Files
`README.md` (overview), `docs/features.md`, `docs/architecture.md`, `docs/roadmap.md`, `assets/` (SVG banners and images).

## Rules (public repository)
- Never add live configuration, IP addresses, hostnames, Tailscale names, ports, usernames, device IDs, tokens, personal schedules, email/financial/health data, or anything that maps the private network.
- Describe capabilities and decisions at the design level. Use fictional or generic examples.
- Never claim something is deployed or working unless the user confirms it; mark plans as plans.
- Keep the Catppuccin visual style consistent across SVG assets.

## Working conventions
- Branch per change; preview Markdown and Mermaid rendering before committing.
- Keep README links and `docs/` cross-links valid.
